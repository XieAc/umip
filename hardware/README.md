# 硬件模型（SolidWorks）

XAC 手持采集夹爪和 UR5 执行夹爪的三维模型。两者共用 XC330 电机、夹爪套和软指尖，采集端多了手持底座，执行端多了法兰连接。

| 路径 | 内容 |
|---|---|
| `model_v1/采集部分/` | 第一版采集夹爪：装配体 `采集器.SLDASM`、`执行器.SLDASM`、`电机组合.SLDASM`，及底座、夹爪套、软夹爪等零件（部分附 STL） |
| `model_v1/执行器部分/` | 第一版执行夹爪：`执行器.SLDASM`、`电机组合.SLDASM` 及零件 |
| `model_v2/` | 第二版：`采集装备v2.SLDASM`、`执行器.SLDASM`、`1.SLDASM`，及 `电机底座v2/v2.1`、`采集装备底座v2`、`夹爪套_left/right`、`软夹爪30`、`指尖`/`指尖21`/`指尖倒模` 等零件 |
| `法兰.SLDPRT` | 执行夹爪与 UR5 的连接法兰 |
| `1.png` ~ `6.png` | 图片 |

`XL,XC-330.SLDPRT` 是 Dynamixel XC330 电机的外形模型。打开装配体前把同一目录下的零件放在一起，SolidWorks 按相对路径查找零件。

注意：执行端夹爪的相机与手指相对位置必须和采集端一致，否则模型看到的画面和演示不同，夹取时机会判断不准
（2026-10-29 真机测试的教训，见 `deployment/docs/model_xac_v3_h1img1_800ep_20261025.md` 的"已知问题"）。
